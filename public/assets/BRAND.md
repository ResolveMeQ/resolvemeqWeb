# ResolveMeQ brand assets

Use these SVGs anywhere (web, docs, slides, partners). Prefer SVG; rasterize only when a host requires PNG.

## Quick pick

| Need | File |
|------|------|
| Favicon / app icon | `logo-app-icon.svg` or `/favicon.svg` |
| Sidebar collapsed / avatar | `logo-mark.svg` |
| Header / auth (light bg) | `logo-lockup.svg` |
| Header / auth (dark bg) | `logo-lockup-on-dark.svg` |
| Tall placements / splash | `logo-stacked.svg` / `-on-dark` |
| Text-only | `logo-wordmark*.svg` |
| Single-color print / watermark | `*-mono-black.svg` / `*-mono-white.svg` |

## Naming

- **mark** — icon only (gear)
- **lockup** — mark + ResolveMeQ (horizontal)
- **stacked** — mark above ResolveMeQ
- **wordmark** — ResolveMeQ text only
- **on-dark** — tuned for dark backgrounds
- **mono-black / mono-white** — single-color

## Colors

- Brand cyan: `#06B6D4` / `#22D3EE`
- Ink: `#0F172A` / `#0B1220`
